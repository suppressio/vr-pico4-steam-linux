# Pico 4 VR on Linux

How to play SteamVR games on a **Pico 4** headset from a **Linux** PC (Debian-based), streaming them over Wi-Fi. A guide only: there is no software to install from this repository.

There are two ways:

| Method | What it needs | Notes |
|---|---|---|
| [**Steam Link VR**](docs/STEAM-LINK.md) (2026, recommended) | the Steam Link VR app from the Pico Store, SteamVR on the public beta | much simpler to set up, better colours and latency; Linux support is still experimental, with occasional disconnections |
| [**ALVR**](docs/ALVR.md) | ALVR Streamer on the PC, the ALVR Client `.apk` on the headset | the manual way, step by step with screenshots; also over a [USB cable](docs/ALVR-USB.md) |

Start with Steam Link VR; if it does not work on your system, fall back to ALVR.
